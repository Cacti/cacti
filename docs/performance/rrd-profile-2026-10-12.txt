RRDtool performance profile, 2026-10-12

The measured improvement is graph-option preparation: 257.90 to 70.65 microseconds per call, 72.6% less time, with PHP CLI OPcache enabled. These timings describe the tested component, not complete graph rendering or production polling throughput.

Problem and change

Graph-option construction included global_arrays.php on every call even though Cacti's normal bootstrap had loaded its image-format map. The include rebuilt unrelated arrays and translated their labels. Reuse the loaded map, with the original include retained for callers whose map is absent.

GraphOptions also configured the same OptionsResolver rules on every call. Retain one configured resolver per PHP process. Symfony clones it for each resolution; input values and plugin options are never cached. Successful, failed and empty resolutions remain independent.

Method

Compare the common develop ancestor d49126df58c8290f8c788537cb2f179cf9e2cd14, PR #8012 at c3019e2b6b6ef07e3280e8298965d2ac0972862a, and the optimized source hashes in the adjacent JSON record. Run five rotating rounds to reduce ordering bias. PHP 8.5.11, RRDtool 1.11.0, macOS arm64, CLI OPcache enabled, JIT disabled. Each checkout uses its own locked Composer dependencies. Timings exclude bootstrap, warm-up and fixture creation.

Persistent-update and local-update modes execute the public rrdtool_function_update function against a disposable RRD, verify the successful update count, and confirm the final timestamp and value 42. A batch contains 3,000 timestamps for one fixture RRD.

The isolated graph-options profile records 600 repeated global array includes before the fix and none afterwards, with one bootstrap load in either case. Xdebug 3.5.3 profiling runs are separate from all reported uninstrumented timings. Raw profiles are retained outside the repository at /tmp/cacti-rrd-profile-evidence-20261012.

Persistent and local updates show no established improvement from the graph changes. Keep the existing persistent process in the polling path: a fresh process per update is substantially more expensive in this fixture. LocalRrdTransport is available as a component but is not used by the procedural poller path. Do not substitute its standalone timings for poller measurements.

Command construction was also exercised at 150,000, 1,000,000 and 2,500,000 iterations. Peak PHP allocated memory remains 6 MiB in these bounded synthetic loops. They do not load millions of data sources or measure network, database or production disk throughput. The JSON includes raw samples, ranges, counts and source hashes.

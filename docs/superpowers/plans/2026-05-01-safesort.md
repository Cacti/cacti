# SafeSort Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement automatic sorting protection (SafeSort) to mitigate SQL injection in `sort_column` and `sort_direction` parameters across the entire Cacti web interface.

**Architecture:** 
1. Strict direction validation (`ASC`/`DESC`) in the core `update_order_string()` helper.
2. Automatic registration of valid sort columns in the session via `html_header_sort()` functions.
3. Session-based allowlist enforcement in `get_order_string()`.
4. Strict regex fallback for non-registered columns.

**Tech Stack:** PHP, Pest (PHPUnit), Playwright (E2E).

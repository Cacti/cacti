# Basalt

A midwinter child theme whose light and dark palettes follow the Gray 10 and
Gray 100 themes of IBM's Carbon Design System: neutral grays, a single blue
interactive color and square, dense tables suited to long device lists.

Only the palette, fonts and graph colors live here. Layout, behavior and every
other file come from `midwinter` through the `parent` file.

The color values are taken from Carbon's published design tokens. Carbon is
licensed under the Apache License 2.0. No IBM logos or marks are used.

The sans-serif stack prefers IBM Plex Sans when it is installed and falls back
to the midwinter stack. Plex is not bundled.
